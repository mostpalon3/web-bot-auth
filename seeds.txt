# HOW TO POPULATE THIS PROPERLY  (do this before the first real run)
#
# 1. Cloudflare's bot and signed-agent documentation lists the operators it
#    recognises. Start there — it is the closest thing to a public roster.
# 2. draft-meunier-webbotauth-registry describes registry discovery. Follow it
#    to whatever registry instances actually exist; the draft describes the
#    mechanism, not a deployment.
# 3. IETF web bot auth mailing list and meeting materials name implementers.
# 4. Operators that publish crawler documentation (AI vendors, search engines,
#    SEO and monitoring tools) are the obvious candidates to test.
# 5. Passive discovery, and the most reliable source: run E3's honeypot and
#    read Signature-Agent headers off real traffic. Any host that signs a
#    request to you tells you where its directory is. Seeds harvested this way
#    are observed rather than guessed, and should eventually replace this list.
#
